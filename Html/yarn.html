What is NPM? npm Default package manager that comes with Node.js Uses package.json to manage dependencies Stores packages in node_modules Basic Commands: npm init # create package.json npm install express # install package npm install # install all dependencies npm uninstall express npm update 2.What is Yarn? Yarn Developed by Facebook Faster and more efficient (especially older versions) Uses yarn.lock for consistent installs Basic Commands: yarn init yarn add express yarn install yarn remove express yarn upgrade Use NPM → simple, already installed Use Yarn → better performance, strict dependency control
