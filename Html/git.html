1. What is Git? Git is a version control system used to track changes in your code. A “save history” for your project You can go back to previous versions anytime Multiple developers can work together safely Key Features: Tracks changes (who changed what & when) Works offline Supports branching (parallel work) 2. What is GitHub? GitHub is a cloud platform where you store Git repositories online. Git = tool GitHub = place to store & share code Uses: Backup your code Collaborate with team Share projects publicly Basic Git Workflow Working Directory → Staging Area → Repository Make changes Add changes Commit changes Push to GitHub Important Git Commands:- 1. Initialize Git git init //Creates a new Git repository 2. Check Status git status //Shows changed files 3. Add Files (Staging) git add file.txt git add . 4. Commit Changes git commit -m "Added new feature" 5. Connect to GitHub Repo git remote add origin 6. Push Code to GitHub git push origin main 7. Pull Latest Changes git pull origin main 8. Clone Repository git clone 9. Create Branch git branch feature-1 10. Switch Branch git checkout -b feature-1 11. Merge Branch git merge feature-1 Common Terms:- Repository (Repo) → Project folder Commit → Saved snapshot Branch → Separate line of work Merge → Combine branches Clone → Copy repo Push → Upload to GitHub Pull → Download updates
